# GAT315 - Physics Engine

## Description

This project was created for GAT315 Physics. The purpose of this project is to create a custom 2D physics simulation and gain a better understanding of how physics systems work behind the scenes.

The simulation allows users to create physics bodies, connect bodies with springs, and experiment with different types of effectors. The project includes concepts such as gravity, velocity, acceleration, damping, collision detection, collision response, mass, restitution, and force calculations.

A GUI is included to allow different physics values to be adjusted in real time. This makes it possible to test how different settings affect the simulation without needing to recompile the project.

## Features

* Custom physics simulation
* Dynamic and static bodies
* Collision detection and response
* Gravity simulation
* Spring connections between bodies
* Point effectors
* Gravitational effectors
* Area effectors
* Drag effectors
* Adjustable physics settings through a GUI
* Real-time simulation controls

## Controls

| Input                                | Action                                |
| ------------------------------------ | ------------------------------------- |
| Left Click                           | Create a physics body                 |
| Left Ctrl + Left Click               | Create multiple bodies while dragging |
| Left Alt + Left Click                | Create an effector                    |
| Right Click on Body                  | Select a body                         |
| Right Click and Drag to Another Body | Create a spring between bodies        |
| Left Ctrl + Right Click              | Apply spring force to selected body   |
| Space                                | Pause / Resume simulation             |
| Tab                                  | Show / Hide physics panel             |
| Left Shift                           | Slow down simulation speed            |
| Right Shift                          | Speed up simulation speed             |
| Right Ctrl                           | Greatly increase simulation speed     |
